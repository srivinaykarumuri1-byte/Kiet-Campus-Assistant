## 📌 Project Overview
The **KIET Campus Assistant** serves as an automated digital guide for students, faculty, and visitors. Built with conversational AI, it provides instant answers to common campus inquiries, academic details, and administrative workflows.

### ✨ Key Features
- **Instant Query Resolution:** 24/7 conversational support for campus-related questions.
- **Student-Centric Interface:** Clean, intuitive UI optimized for both desktop and mobile screens.
- **Accurate Information Retrieval:** Direct answers regarding admissions, campus facilities, events, and department contacts.
